### 👨‍💻 About me

I'm a **Senior Software Engineer from Brazil** with 10+ years of experience building production software across backend, frontend, cloud infrastructure and distributed systems.

I mainly work with **Java, Spring Boot, Node.js, TypeScript, React, Next.js and AWS**, focused on backend architecture, APIs, microservices, developer experience and systems that stay maintainable.

I enjoy problems involving **system design, performance, automation, cloud architecture and developer tooling**, and lately, a whole Linux desktop.
